# What PR #311 could break

**fix: use PUT method for article updates in editor** · [https://github.com/realworld-apps/angular-realworld-example-app/pull/311](https://github.com/realworld-apps/angular-realworld-example-app/pull/311)

> Editing an existing article now saves with an update request instead of a create request. Creating a new article works as before.

5. Run the flow "Publish a new article" as a regression check. It still creates the article, but now sits behind the new check for an article address. *(Medium confidence)*
6. Re-run the tests that edit an article and click Publish Article: "should edit an existing article", "should remove all tags when editing an article", "should handle 403 when updating article" and "should show error message on update article form when network fails". The two error tests cover failures that only happen on the new update path. *(High confidence)*

## What the change does

- The editor's submit used to always send a create request. Now it checks the article address in the page URL. *(High confidence)*
- With an article address, it sends an update (PUT). Without one, it sends a create (POST). *(High/Medium confidence)*
- The Publish Article button on the existing-article editor page now sends the update call. The same button on the new-article page still sends the create call. *(High confidence)*

## Coverage with no trusted result until re-run

- All 28 tests that check the Publish Article button go through changed UI. Until they are re-run and pass, this button has no trusted coverage. *(High confidence)*
- All 5 tests that check the update call go through changed UI. Until they are re-run and pass, this call has no trusted coverage. *(High confidence)*

## Lower risk

- Create-path tests only need a regression check: "should create a new article", "should handle 400 on article creation" and "should show error message on create article form when network fails". *(Medium confidence)*
- The delete-article and favorite-article flows use the editor only to create an article in setup. The change does not affect them. *(Medium confidence)*
